# 자율주행 시뮬레이션

# <기본조건>
1. 출발 후 차량 30초 이상 주행
   - 차량의 가/감속 주행. 출발 시 속도 0에서 가속 출발, 정지 시 속도 0으로 감속 정지
2. 시간 (step) 기반 이동
3. python, bullet 물리엔진 사용 필수 (예:PyBullet)

# <환경 구성> 
1. 환경에 따라 이동 방식(속도, 방향 등)이 달라져야 함
   - 평면 (Flat surface)
   - 기울어진 평면 (Inclined plane)
   - 곡면 (예: 원형, 포물면 등은 물론 새로운 곡면 적용 가능)

# <차량 모델 설계>
1. Bullet 물리엔진 기반으로 차량을 정의하고 다음 요소를 포함할 것
   - 차량의 물리적 크기 (length, width 등)
   - 질량 (mass)
   - 최대 속도
   - 가속/감속 특성
   - 필요 시 마찰, 바퀴 특성 등 추가
  
# <주행 규칙 적용> 
1. 연료 소비 규칙
   - 출발 시점의 연료양과 주행 중 연료 감소율 설정
   - 이동 중 연료 감소
   - 연료 무게가 변화로 차량 무게 변화
   - 연료가 0이면 정지 (주행 중 연료 부족하지 않도록 연료령 설정 필요)
  
2. 특정 조건에서의 방향 전환
   - 주행 환경 경계에서의 방향 전환, 일정 시간/거리 주행 후의 방향 전환
   - 급격한 경사/곡률 진입 이전의 방향 전환 등
  
   (최소 2개 이상의 규칙 적용)
   - 규칙은 코드 반영되어 차량 주행에 영향을 주어야 함
   - 보고서에 규칙과 차량 주행의 영향과 그 결과 설명

   - 규칙 작동 여부 표시
